# vibes

## Projects

###  [fifa](./fifa)
A live football score tracker for your terminal (TUI), with a big scoreboard, match clock, stat bars, and goal animations. Also runs as a one-line status for your tmux/shell prompt.

###  [habits](./habits)
A habit tracker app for iOS, built with SwiftUI + SwiftData. Log each day into a GitHub-style heatmap, with streaks, stats, daily reminders, and a home-screen widget.

###  [looper](./looper)
A Chrome extension that loops a section of any YouTube / YouTube Music track between a start and end point you set.
